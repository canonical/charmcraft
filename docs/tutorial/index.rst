.. _tutorial:

Tutorials
=========

The tutorials are guided lessons that help you develop skills by using Charmcraft. Each
is self-contained and delivers a working result that marks a learning milestone and is
an opportunity for further exploration. If you're a newcomer to Charmcraft, this is the
best way to start.


12-factor app extensions on Ubuntu 26.04
----------------------------------------

These tutorials port the original development workflows to the experimental
Ubuntu 26.04 extensions. Each lesson creates and tests an app, builds its rock
and charm, and deploys it with Juju. You'll then update the app, configure it
through ``paas-config.yaml``, and integrate it with PostgreSQL:

Choose your framework in the :ref:`Ubuntu 26.04 tutorials <tutorial-ubuntu-26-04>`.


12-factor app extensions on lower bases
---------------------------------------

With Charmcraft extensions, you can charm 12-factor web applications with just a few
modifications to the YAML template content. To get started, check out the tutorial for
your desired web framework:

- :ref:`write-your-first-kubernetes-charm-for-a-django-app`
- :ref:`write-your-first-kubernetes-charm-for-a-expressjs-app`
- :ref:`write-your-first-kubernetes-charm-for-a-fastapi-app`
- :ref:`write-your-first-kubernetes-charm-for-a-flask-app`
- :ref:`write-your-first-kubernetes-charm-for-a-go-app`
- :ref:`write-your-first-kubernetes-charm-for-a-spring-boot-app`
