``SECURITY.md`` file
====================

The ``SECURITY.md`` file describes the security policy for the charm. Charmcraft creates this file only when the profile is ``machine`` or ``kubernetes``.

By default, the file points to the GitHub private vulnerability reporting
feature. Charms must have a security policy to be publicly listed on Charmhub.
